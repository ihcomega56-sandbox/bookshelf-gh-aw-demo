## 参照させないための運用

「答えを知らない状態で調査させる」ことを狙うなら、以下の点に注意してください。

- **Knowledge Base からの除外だけでは不十分です。** Knowledge Base は Copilot Chat が
  追加の文脈を検索するための仕組みであり、除外しても、リポジトリを checkout して動く
  エージェント（Agentic Workflow / Copilot coding agent）は `grep` や `cat` でこのファイルを直接読めます。
- 確実に隠したい場合は、**リポジトリの作業ツリーに置かない**のが唯一確実な方法です。例:
  - デモ用リポジトリとは別のプライベートリポジトリ / Gist に置く
  - ローカルにのみ置き、`.gitignore` で追跡対象から外す
  - デモ実行時のブランチには含めず、答え合わせ用のブランチにのみ置く
- リポジトリに残す場合は、**ワークフローの指示（`.github/workflows/*.md`）で明示的に読まないよう指定する**方法もありますが、
  これは「お願い」であって強制力はありません。厳密な検証には向きません。
